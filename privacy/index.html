Privacy Policy

Last updated: September 29, 2026

Genie is a conversational guessing game. The game is designed so that the guessing state stays in the conversation and is not intentionally stored by Genie's MCP server.

Information we receive

Genie's server receives the requests required to provide the MCP service. We do not intentionally request or store passwords, credentials, payment information, or other sensitive personal information.

Service providers

The service is hosted by Vercel. Hosting infrastructure may process technical information such as request metadata and logs according to its own policies.

Contact

For privacy questions, contact us through Genie's GitHub issues.
