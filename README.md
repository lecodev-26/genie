# 🧞 Genie

Piensa en cualquier cosa. Genie te hace preguntas adaptativas e intenta adivinarla.

## Uso
Di "Genie" o "quiero jugar a adivinar" y empieza la partida.

## Instalar (Claude Code)
    claude plugin marketplace add lecodev-26/genie
    claude plugin install genie@genie-marketplace

## Estructura
- `.claude-plugin/plugin.json` manifest
- `skills/genie/SKILL.md` la skill
- `assets/icon.png` icono
